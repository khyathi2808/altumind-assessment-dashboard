Connect to your assessment data

This dashboard is static — it has no server of its own. Paste either the Google Sheet link (read directly, no deployment or key needed; multiple choice is marked by the sheet's Correct? column, written and video answers by the Scores tab) or an Apps Script Web App URL plus its admin key.

The admin key is kept only in this browser tab's session storage — it is never written to this repository, never sent anywhere but your own backend, and clears when you close the tab.
